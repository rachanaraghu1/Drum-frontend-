# 🥁 Drum Kit Game

An interactive browser-based Drum Kit built with **HTML**, **CSS**, and **JavaScript**. Trigger drum sounds by clicking the on-screen buttons or pressing the corresponding uppercase keys (`W`, `A`, `S`, `D`, `J`, `K`, `L`) on your keyboard.

## 🎹 Controls & Sounds

| Key | Audio File | Drum Sound |
| :---: | :--- | :--- |
| **W** | `tom-1.mp3` | Tom 1 |
| **A** | `tom-2.mp3` | Tom 2 |
| **S** | `tom-3.mp3` | Tom 3 |
| **D** | `tom-4.mp3` | Tom 4 |
| **J** | `crash.mp3` | Crash Cymbal |
| **K** | `kick-bass.mp3` | Kick Bass |
| **L** | `snare.mp3` | Snare |

---

## ✨ Features

- **Keyboard & Click Support:** Play beats using either mouse clicks or physical keyboard presses.
- **Instant Audio Playback:** Uses the native JavaScript `Audio` constructor to play `.mp3` drum samples on demand.
- **Lightweight & Dependency-Free:** Built purely with vanilla HTML, CSS, and JavaScript.

---

## 🛠️ Tech Stack

- **HTML5** – Drum button layout and structure
- **CSS3** – Styling and visual layout
- **JavaScript (ES6)** – Event listeners (`click` & `keydown`), `switch` routing, and HTML5 `Audio` playback
